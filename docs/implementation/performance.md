# Performance methodology and results

## Method

Measure cold and warm process-to-first-frame latency, composition, encoding, console write duration and bytes, presented frame pacing, input-to-action latency, app/host CPU, private bytes, and resize recovery. Record OS build, CPU, architecture, terminal, shell, font, publish mode, viewport and workload. Use 120×30 with three modules for Phase 1, then 120×30/six and 160×45/eight for later phases. Use monotonic timestamps and at least 30 launch repetitions. Capture terminal output in a controlled harness and perform visible tests on a real frontend.

## Results

No performance measurements have been run. See [current performance results](performance-results.md). No benchmark claim is made.
